\chapter{Source Repositories}\label{app:repos}

The thesis artefacts are published in the following GitHub repositories:

\begin{itemize}
    \item \url{https://github.com/dpttk/runc} --- hardened OCI runtime fork with \texttt{--security-scan};
    \item \url{https://github.com/dpttk/runc-hardened-test} --- security laboratory used in Chapter~\ref{ch:experiments};
    \item \url{https://github.com/dpttk/performance-testing} --- performance evaluation harness and published \texttt{results/latest} campaign artefacts;
    \item \url{https://github.com/dpttk/security-evaluation} --- kernel-boundary attack corpus and security matrix harness (campaign \texttt{20260618-220913}).
\end{itemize}
